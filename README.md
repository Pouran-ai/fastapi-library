# fastapi-library
A FastAPI-based backend for a liberary management system , featuring ...

## 
- Add new books to the liberary.
-  Interactive API documentation via Swagger UI (/docs).
-  Retrieve a list of all available books.
-  Update book details (Future).
-  Delete a book from the liberary (Future).
